IT ASSISTANT

Política de privacidad

Última actualización: 20 de octubre de 2026 · Versión de referencia: 1.60.47

Esta política describe cómo IT Assistant trata información al ayudar a gestionar incidencias de soporte técnico, contactos, plantillas, notas y recordatorios. Se aplica tanto a las herramientas locales como a las integraciones que el usuario configure y autorice.

Responsable de la publicación y contacto de privacidad: Miny, mantenedor de IT Assistant. Puedes escribir a Minyfriki@gmail.com. El tratamiento realizado por la organización titular de los portales sigue sujeto a sus propias políticas y responsabilidades.

El paquete de distribución no incorpora una base de empleados ni destinos corporativos precargados. Para usar las integraciones, el usuario importa un archivo local de configuración y concede acceso a los destinos indicados. Esto no significa que la extensión no trate datos tras configurarla.

1. Información que puede tratar

  • Identificación y contacto: nombre del técnico configurado, nombres de contactos, correos electrónicos, teléfonos y, cuando los portales los faciliten, datos profesionales como puesto, departamento, provincia o delegación. No se utiliza geolocalización del dispositivo para localizar al usuario.
  • Incidencias y contenido de los portales: identificadores y enlaces de tickets, descripción, fase, estado, responsable, fechas, observaciones y comentarios de técnicos y usuarios. Los comentarios pueden contener comunicaciones personales.
  • Seguimiento: registros de contactos, intentos de llamada y sus fechas, notas y avisos creados por el técnico. No se graban llamadas ni se utiliza el micrófono para estas funciones.
  • Portapapeles: mientras el asistente de detección está activo, lee texto para identificar teléfonos compatibles e iniciar su consulta. El correo electrónico se busca manualmente. No se conserva un historial general del contenido del portapapeles; sí pueden conservarse los contactos y registros de seguimiento derivados de teléfonos detectados.
  • Sesión de los portales: el adaptador de consulta puede conservar temporalmente en memoria de la página cabeceras de autorización de una sesión ya iniciada para realizar consultas al servicio correspondiente. No se exportan al archivo de configuración ni se almacenan deliberadamente como credenciales persistentes de la extensión. Los restablecimientos de contraseña o segundo factor se tramitan en el portal autorizado con las confirmaciones previstas.
  • Configuración y archivos elegidos: preferencias, plantillas, categorías, configuración de integraciones y datos de los archivos o carpetas que el usuario vincule para la WIKI, calendario o copias de seguridad.

La extensión no está diseñada para recopilar datos sanitarios ni financieros, elaborar perfiles crediticios, registrar todas las pulsaciones del teclado o crear un historial general de navegación. El contenido libre de una incidencia o nota puede incluir información adicional introducida por el usuario; no debe incorporarse información innecesaria para el soporte.

2. Finalidad y acceso

La información se utiliza exclusivamente para las funciones visibles de soporte: localizar contactos e incidencias, completar formularios solicitados, organizar el seguimiento, consultar documentación, aplicar preferencias visuales y entregar recordatorios. La extensión puede inspeccionar las direcciones de pestañas para localizar los portales configurados y comprobar que una operación se realiza en el destino correcto.

Las integraciones requieren autorización de acceso a los orígenes HTTPS indicados al importar el perfil. La configuración no concede derechos adicionales en los sistemas de la organización: el usuario debe disponer de una sesión y de las autorizaciones corporativas necesarias.

3. Almacenamiento y conservación

Las preferencias y datos de trabajo se guardan principalmente en el almacenamiento local del perfil de Chrome. La información de seguimiento puede permanecer hasta que el usuario la elimine, sustituya o desinstale la extensión. La desinstalación elimina el almacenamiento propio de la extensión gestionado por Chrome, pero no borra los tickets de los portales ni los archivos exportados.

Las notas, plantillas y seguimientos no se eliminan al desactivar las integraciones. Las copias de seguridad y archivos guardados en carpetas elegidas por el usuario permanecen allí hasta que se borren expresamente. Si esas carpetas se sincronizan mediante un servicio externo, su sincronización depende de la configuración del usuario y de las condiciones de ese servicio.

El almacenamiento local y el JSON de configuración no constituyen un sistema de cifrado adicional. El usuario y la organización deben proteger el dispositivo, su perfil de navegador y sus copias de seguridad.

4. Comunicaciones y destinatarios

Las herramientas locales no requieren un servidor propio del mantenedor para almacenar el contenido de trabajo. Las integraciones sí pueden comunicarse mediante HTTPS con los servicios configurados y autorizados, enviando las consultas y datos necesarios para la acción solicitada. Los datos introducidos o enviados a esos portales quedan sujetos a sus políticas de conservación y acceso.

IT Assistant no incorpora servicios de publicidad ni analítica de terceros para explotar los datos de soporte. No vende datos de usuario ni los utiliza para publicidad, finalidades ajenas al soporte o decisiones crediticias. No transfiere datos a terceros fuera de los usos necesarios para las funciones solicitadas, las exportaciones realizadas por el usuario o las obligaciones legalmente aplicables.

La política se aloja en GitHub Pages. Al visitarla, el proveedor de alojamiento puede tratar datos técnicos de la petición conforme a su declaración de privacidad. Esta página no añade formularios de recogida, analítica, fuentes remotas ni scripts de seguimiento.

5. Control, eliminación y consultas

El usuario puede editar o eliminar notas y otros datos mediante las funciones disponibles, desactivar integraciones en Ajustes, revocar permisos desde Chrome y desinstalar la extensión. Debe borrar por separado las exportaciones y copias que haya creado. Para corregir o eliminar información existente en los portales corporativos debe dirigirse a su organización.

Para consultas sobre privacidad o para solicitar orientación sobre acceso, rectificación, eliminación u otros derechos que resulten aplicables, contacta con Minyfriki@gmail.com. No envíes contraseñas, tokens, archivos de configuración internos ni información confidencial de incidencias por este medio. El mantenedor no dispone de acceso automático al contenido guardado en tu navegador.

6. Código y uso limitado

El código ejecutable de IT Assistant se distribuye dentro del paquete de la extensión. El perfil importado aporta datos de configuración; no descarga módulos ejecutables. El uso de los datos se limita a proporcionar las funciones de soporte descritas. El uso de información recibida de las API de Google, si resultase aplicable, se ajustará a la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado.

7. Cambios en esta política

La política se actualizará cuando cambie el tratamiento de datos. La fecha de esta página permite identificar su revisión. Los cambios que requieran nuevos permisos o consentimiento deberán comunicarse conforme a los requisitos aplicables.
